# 🤖 Telegram Paper Trading Bot – GRAM / USDT

ربات تلگرام **شبیه‌سازی ترید** بین **GRAM** و **USDT**.

با **GitHub Actions** هر ۵ دقیقه یک‌بار اجرا می‌شود و نتیجه را در کانال تلگرام پست می‌کند.

> ⚠️ این ربات پول واقعی جابه‌جا نمی‌کند. فقط شبیه‌سازی آموزشی است.

---

- `bot.py` → نسخه معمولی (اجرا روی کامپیوتر)
- `.github/workflows/trade.yml` → تنظیمات Actions
- `requirements.txt`
- `.env.example`
- `.gitignore`
- `LICENSE`

## راه‌اندازی سریع با GitHub Actions

### ۱. آپلود فایل‌ها
همه فایل‌ها را در یک ریپوزیتوری جدید در گیت‌هاب آپلود کنید.

### ۲. تنظیم Secrets (خیلی مهم)
1. برو به **Settings** → **Secrets and variables** → **Actions**
2. دو Secret بساز:

| Name             | Value                          |
|------------------|--------------------------------|
| TELEGRAM_TOKEN   | توکن ربات از @BotFather        |
| CHANNEL_ID       | آیدی کانال (مثل -1001234567890) |

### ۳. فعال‌سازی
1. تب **Actions** را باز کن
2. اگر پیغام زرد دیدی Enable را بزن
3. از سمت چپ **GRAM Trading Bot** را انتخاب کن
4. **Run workflow** را بزن تا تست شود

بعد از این هر ۵ دقیقه خودکار کار می‌کند.
